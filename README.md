## Project Description
FleetCare is a web-based automotive emergency platform powered by Directus CMS
that connects stranded motorists with certified mobile mechanics. It features
Google Maps integration for pinpointing breakdown locations, broadcasting distress
radiuses, and tracking mechanic arrivals, secure billing through Stripe/PayPal
Sandbox, and automated email alerts via SMTP. Motorists pay a support fee for
roadside dispatch plus a main fee scaled to the severity of the mechanical issue.

## Technologies Used
- HTML5, CSS3, JavaScript
- Directus CMS (backend and authentication)
- Google Maps JavaScript API
- Stripe / PayPal Sandbox
- SMTP Email Integration
- Git and GitHub
